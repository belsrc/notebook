### Creational

**[Abstract Factory](./creational/Abstract%20Factory%20Pattern.md)**: Groups related factories behind a single interface
**[Builder](./creational/Builder%20Pattern.md)**: Constructs a complex object step-by-step via a fluent API
**[Factory Method](./creational/Factory%20Method%20Pattern.md)**: Delegates instantiation to a subclass
**[Prototype](./creational/Prototype%20Pattern.md)**: Clones an existing instance rather than constructing from scratch
**[Singleton](./creational/Singleton%20Pattern.md)**: Restricts a class to one shared instance

### Structural

**[Adapter](./structural/Adapter%20Pattern.md)**: Bridges two incompatible interfaces
**[Bridge](./structural/Bridge%20Pattern.md)**: Separates what something does from how it does it
**[Composite](./structural/Composite%20Pattern.md)**: Treats a leaf and its container uniformly in a tree
**[Decorator](./structural/Decorator%20Pattern.md)**: Layers behavior onto an object at runtime without sub-classing
**[Facade](./structural/Facade%20Pattern.md)**: Narrows a complex subsystem to a simpler surface
**[Flyweight](./structural/Flyweight%20Pattern.md)**: Shares immutable state across many fine-grained objects to reduce memory
**[Proxy](./structural/Proxy%20Pattern.md)**: Intercepts access to another object to control or augment it

### Behavioral

**[Chain of Responsibility](./behavioral/Chain%20of%20Responsibility.md)**: Passes a request along a handler chain until one consumes it
**[Command](./behavioral/Command%20Pattern.md)**: Wraps a request as an object to enable queuing, logging, or undo
**[Interpreter](./behavioral/Interpreter%20Pattern.md)**: Defines and evaluates sentences in a small grammar
**[Iterator](./behavioral/Iterator%20Pattern.md)**: Walks a collection without exposing its internal structure
**[Mediator](./behavioral/Mediator%20Pattern.md)**: Routes all inter-object communication through a central hub
**[Memento](./behavioral/Memento%20Pattern.md)**: Snapshots and later restores an object's private state
**[Observer](./behavioral/Observer%20Pattern.md)**: Notifies subscribed listeners when state changes
**[State](./behavioral/State%20Pattern.md)**: Delegates behavior to a swappable state object
**[Strategy](./behavioral/Strategy%20Pattern.md)**: Injects an algorithm as a replaceable dependency
**[Template Method](./behavioral/Template%20Method%20Pattern.md)**: Fixes an algorithm's skeleton; subclasses fill the variable steps
**[Visitor](./behavioral/Visitor%20Pattern.md)**: Adds an operation to a type hierarchy without modifying it
